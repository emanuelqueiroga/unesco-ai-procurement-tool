Controle segmentado para escalas fechadas de três a quatro respostas: Sim / Em parte / Não / Não sei.

**Use** na tela única de governança (seis perguntas empilhadas, cada uma com o seu segmentado) e em qualquer pergunta cuja resposta seja uma gradação curta. Para opções com subtexto use `OptionCard`.

**Anatomia**: grupo com `role="group"` e `aria-label`; botões de 44 px, borda `line-control` entre eles, raio `radius-md` no conjunto. Selecionado: fundo `primary`, texto `on-primary`, peso 600. A ordem é sempre a mesma em toda a ferramenta: afirmativo, parcial, negativo, não sei.

**Não** use para mais de quatro opções; não mude a ordem entre perguntas; em 400 px o grupo ocupa a largura toda com os botões dividindo o espaço por igual.
