Aviso breve de confirmação no canto inferior, que some em 4 segundos.

**Use** para confirmar exportação, importação, cópia de texto e salvamento. Uma frase, no máximo um link de ação ("Desfazer").

**Anatomia**: fundo `ink`, texto `surface-1`, `radius-md`, `shadow-md`, `role="status"`; posição inferior direita em desktop, inferior centralizada em celular, nunca sobre o botão primário.

**Não** use toast para erro (use `Alert` no lugar certo) nem para elogio; não empilhe mais de um.
